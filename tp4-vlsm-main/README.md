# TP 4 : Adressage VLSM et Configuration Cisco

## Objectifs du travail
Ce TP vise à concevoir et implémenter un plan d'adressage optimisé (VLSM) pour un réseau d'entreprise segmenté. Les objectifs sont :
- Calculer l'adresse réseau d'origine à partir d'une IP hôte et d'un masque.
- Concevoir un plan VLSM respectant des besoins spécifiques (Départements A, B, C, D, Guest, Management).
- Configurer des équipements Cisco (Switchs et PCs) pour vérifier la connectivité intra-VLAN.
- Démontrer l'absence de routage inter-sous-réseau par défaut.

## Technologies utilisées
- **VLSM (Variable Length Subnet Mask)** : Optimisation de l'espace d'adressage.
- **Cisco Packet Tracer** : Simulation de la topologie réseau.
- **Commandes IOS** : Configuration IP de base.

## Contenu du dépôt
1. **Rapport technique** : Détail des calculs, justifications des choix de masques et plan d'adressage complet.
2. **Fichiers de configuration** : Commandes utilisées pour les tests.

## Instructions
1. Compiler le rapport : `pdflatex rapport_tp4.tex`.
2. Utiliser le plan d'adressage du rapport pour configurer la maquette Packet Tracer.
